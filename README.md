# ella-bache-brain

Ella Baché Hobart's second brain: the rules and skills Claude follows when it works on the business.

- **[CLAUDE.md](CLAUDE.md)**: the rules every task reads first, plus a map of this repo and the Notion workspace.
- **skills/**: one folder per recurring job (salon facts, brand voice, skin-care-expert, writing, local SEO).
- **templates/schema/**: structured data templates.
- **[CHANGELOG.md](CHANGELOG.md)**: every rule or skill change, linked to the Feedback item that prompted it.

The work itself (tasks, routines, projects, knowledge, decisions, feedback) lives in Notion: [Ella Baché Brain](https://www.notion.so/40e76ddcbf5981cfb8f8d5857dd26248).

Changes go through pull requests. Nothing is committed straight to `main`.

Built from the same pattern as the Icon Footwear brain (icon-footwear/icon-footwear-brain).
